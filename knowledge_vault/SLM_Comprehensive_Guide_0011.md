# Step 1: Data Preparation & Prompt Formatting

Format your dataset into a uniform instruction-response format matching the model's native chat template (e.g., ChatML format): Uniform Schema: Map data into JSON instances containing `instruction`, `input`, and `output` fields. Concise Targets: Keep target outputs high-signal, concise, and strictly formatted to prevent conversational rambling.
