# 3. Model Selection Guide: When to Use Which SLM

Selecting the correct SLM depends on specific workload constraints, licensing requirements, and operational latency budgets: Alibaba Qwen Series: Choose Alibaba Qwen (e.g., Qwen2.5-3B or 7B) when you need robust multilingual support, extensive context windows, complex multi-turn agent conversations, or strict JSON schema compliance. Microsoft Phi Series: Choose Microsoft Phi (e.g., Phi-4-mini) when your primary task involves deterministic structured data extraction, mathematical logic, code generation, or when an MIT license is mandatory for commercial distribution. Google Gemma Series: Choose Google Gemma (e.g., Gemma-2-2B) when deploying onto mobile apps, edge devices, or client-side environments requiring minimal memory overhead.
